# 🧠 Simon Game (Built with jQuery)

This is a browser-based implementation of the classic **Simon Game**, where players must repeat an increasingly long sequence of colors and sounds. The game challenges memory and concentration using interactive UI and sound effects.

- **[jQuery](https://jquery.com/)**

## 🎮 How to Play

1. Press any key to start the game.
2. Watch the sequence of colored buttons flash.
3. Click the buttons in the same order.
4. Each level adds one new color to the sequence.
5. If you click the wrong button, the game ends and shows a "Game Over" message.

## ✨ Features

- Color buttons light up and play sound on interaction
- Tracks the user's input and compares it with the game pattern
- Level progression with increasing difficulty
- "Game Over" animation and reset functionality
